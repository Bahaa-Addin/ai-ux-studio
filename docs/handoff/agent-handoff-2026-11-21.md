The lead then fixed that check's two new findings: split's `fitRail()` hands the focus on (Next, Previous or the stage) before a focused rail button is hidden, and ring and split fall back to the stage (`tabindex -1`) when both buttons are disabled, as fan and gallery do; he also corrected `box.js`'s `H_MIN` comment (measured from `W_MIN` to 400 px, not to `WIDE`). - **Rules (B-98, B-99):** on pages not about services the composer, the view bar and the announcement said "Service ring" / "Service cube" (and the Arabic); streaming's preview did not give the focus back when a resize made its opener inert while it was open; Space on a focused link in the box preview was not held (it could scroll Vodafone's page); the box preview was placed again only on resize (a stale top when the view bar's height changes).

## 7. How to work in this repository (rules and lessons)

- **The shared checkout:** other sessions work in the same checkout and branch. Never stage in the shared git index; commit through a private index (the 4a handoff's Appendix A; the 2026-11-17 handoff's section 7). For a shared file build the blob from `git show HEAD:<path>` plus only your lines (`git hash-object -w --stdin`); for the wiki page use `git merge-file`. After `update-ref` run `git restore --source=HEAD --staged --worktree -- <paths>` once nothing is uncommitted.
- **Peers:** the revamp session ("Voice guide revamp phase 2", `feature/vg-revamp`, ADRs 0068 to 0074 and 0077) runs full suites on ports 4400-4499 and the one Postgres test database: tell it before your full `npm test` or `test:e2e` and wait for "done" or "clear". The phase 6 session (the page watch, `feature/live-way2-watch`, ADR-0078, ports 4720-4739, O45 to O47) is built and not merged.
- **ADR numbering:** 0076 is Reimagine on Vodafone's pages; 0078 is phase 6's; **the next free number is 0079**.
- **Commits carry no `Co-Authored-By` or other attribution lines** (the owner's rule).
- **The scratchpad can be wiped.** On 2026-11-21 a reboot cleared the session's scratchpad: the scratch worktrees, the logs and the lead's scripts. Everything committed was safe. Keep the lead's scripts outside the scratchpad, and `git worktree prune` after a scratch folder is cleared.
- **Environment:** Postgres container `vg-pg` on 127.0.0.1:54329. Node 25. Python Playwright at `/Library/Developer/CommandLineTools/usr/bin/python3`. e2e runs, servers, `lsof` and `git worktree add/remove` need the sandbox off. Always check that a port is free before serving (a stale server gave false failures).
- **The clone must stay as it was:** `shared.js` and the experiences are shared with the Services clone; every box rule sits under `.aixc-box`, and every behaviour that differs on live pages keys on whether a scroller is configured (`viewScroller()`). Its own bugs are recorded, not fixed (O54).
- **Budgets:** `shared.js` is one chunk with the shell, so a helper that one experience uses counts in the shell's budget; put a helper of a few experiences in a chunk of its own (as `view-dialog.js`). Raise a budget only by the smallest step, with a dated note in `sdk-size.test.ts`.
- **Working model the owner asked for:** the main session plans, designs and critiques; implementation goes to Opus subagents with a full brief; low-criticality work to Sonnet; every finding is judged by a refuting skeptic before it is fixed; the main session reads every diff and re-runs every check before committing. Briefs forbid subagents from git commands, from the other sessions' files and from the live site.
